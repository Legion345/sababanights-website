# Assets Directory

## Structure
- `images/` - All images (team photos, backgrounds, gallery photos)

## Usage
Import assets using the `@/` path alias:
```typescript
import harelImage from '@/assets/images/harel-asaraf.jpg';
import ashleyImage from '@/assets/images/ashley-asaraf.jpg';
```

## Image Guidelines
- Use WebP or JPG format for photos (<200KB optimized)
- Use SVG for icons and logos
- Use descriptive kebab-case filenames
- Optimize images before committing
